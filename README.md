# Student Tools Hub

Free, simple calculators and study tools for secondary-school and university students.

## Features

- CGPA Calculator
- GPA Calculator
- Percentage Calculator
- Grade Calculator
- Exam Countdown
- Date Calculator
- Mobile-friendly design
- Responsive layout
- No account required for the calculators

## Technology

Student Tools Hub is built with:

- HTML
- CSS
- JavaScript
- JavaScript ES Modules

No frontend framework is required.
