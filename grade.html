How it works

The calculator compares your score with the minimum score for each grade, starting with the highest threshold.

The default scale is: A = 70–100, B = 60–69, C = 50–59, D = 45–49, E = 40–44, F = 0–39.

You can edit the minimum scores or grade labels to match another grading system.

Frequently Asked Questions

What score range does the calculator accept?

Scores from 0 through 100 are accepted.

Can I change the grading scale?

Yes. Edit the grade labels and minimum scores in the grading scale table.

What happens if two grades have the same minimum?

The calculator will show an error and ask you to use different minimum scores.
