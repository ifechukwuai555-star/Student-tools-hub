How It Works

Enter your score and the calculator compares it with the minimum scores in the grading scale. The highest matching grade is returned.

Default Scale

A = 70–100   B = 60–69   C = 50–59   D = 45–49   E = 40–44   F = 0–39

Frequently Asked Questions

Can I change the grading scale?

Yes. Change the minimum score for each grade to match the grading system you want to use.

What scores are accepted?

Scores from 0 to 100 are accepted, including decimal scores such as 72.5.

What happens if I enter an invalid score?

The calculator will show an error instead of producing an incorrect grade.
